### 分布式文件存储系统 — 基于 mpRPC 框架

- **项目职务**：独立开发
- **时间**：2026.09
- **项目地址**：[GitHub 链接]

**项目描述**：实现一个分布式文件存储系统，客户端将文件切分为固定大小的块分布存储到多个存储节点，元数据服务统一管理文件索引与块位置，支持文件的上传、下载与删除，存储节点故障自动转移。

**主要工作**：

- 【做了什么模块】设计元数据服务（文件索引增删查 + 块位置管理）+ 存储服务（块读写/删除）双服务架构｜【用了什么技术】Protobuf 定义服务接口、自定义二进制协议传输｜【解决了什么问题】文件索引与块数据耦合、单体难以水平扩展｜【达到了什么效果】元数据与存储职责分离，存储节点可独立部署扩缩容
- 【做了什么模块】实现文件分块、块分布多节点存储｜【用了什么技术】固定 1024 字节块切分 + 元数据按块序号取模分配到多个存储节点｜【解决了什么问题】大文件整传易失败、单节点存储瓶颈｜【达到了什么效果】文件按块分布到多节点，客户端直连对应节点读写，单块失败不影响整文件
- 【做了什么模块】扩展 RPC 框架支持直连模式与大响应接收｜【用了什么技术】MprpcChannel 服务发现 + 直连双模式、循环读取至连接关闭｜【解决了什么问题】框架原仅支持 ZooKeeper 自动发现无法按块路由、固定缓冲无法传输大块｜【达到了什么效果】客户端按块位置直连存储节点，支持任意大小块数据传输
- 【做了什么模块】实现分布式服务注册与发现｜【用了什么技术】ZooKeeper 临时节点 + getChildren 故障转移｜【解决了什么问题】节点上下线需客户端感知、宕机后访问失效节点｜【达到了什么效果】节点自动注册/摘除，客户端自动切换可用节点
- 【做了什么模块】实现异步日志模块｜【用了什么技术】独立写线程 + 线程安全队列批量 drain｜【解决了什么问题】存储节点块读写日志频繁、磁盘 I/O 阻塞主流程｜【达到了什么效果】日志批量落盘，写入不阻塞块传输主流程
